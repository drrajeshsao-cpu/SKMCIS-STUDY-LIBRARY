SKMCIS STUDY LIBRARY PWA V1
===========================
Purpose: Study/knowledge system only. No patient records or PHI.

How to publish on GitHub Pages:
1. Create/open a repository.
2. Upload the CONTENTS of this folder to repository root.
3. Settings > Pages > Deploy from branch > main / root.
4. Open the Pages URL in Chrome/Edge and use Install App when available.

V1 content:
- Searchable Master Disease Index (legacy V1 + clinical packs + separate 100-disease Anukta reference layer).
- First Gold Chapter draft: Sciatica / Lumbosacral Radicular Pain with clearly separated Gridhrasi framework.
- Patient education view.
- Source/validation view.
- Favorites + local study-state backup/restore.
- Offline PWA cache.

Safety:
- Do not enter real patient identifiers.
- 'Gold Chapter Draft' means source checked, NOT automatically clinician-validated.
- Missing legacy DIS-0006 to DIS-0015 remain unresolved by design.
